# تقلب‌نامه | TaghalobNameh

مجموعه کتابچه‌های کاربردی فارسی با سه سطح آسان، متوسط و دشوار.

- موضوع فعال: بازی اسم و فامیل
- مرجع اصلی: مخزن GitHub حاضر
- وضعیت: تکمیل زیرساخت و استانداردسازی
- دسته‌ها: آسان ۸، متوسط ۱۲، دشوار ۱۶ ستون
- آسان: اسم، فامیل، شهر، کشور، غذا، میوه، رنگ، حیوان
- متوسط: دسته‌های آسان + اشیا، شغل، گل و گیاه، اعضای بدن
- دشوار: اسم دختر، اسم پسر، فامیل، شهر، کشور، غذا، میوه، رنگ، حیوان، اشیا، شغل، گل و گیاه، اعضای بدن، ماشین، افراد مشهور، ورزش
- دسته مستقل «ابزار» حذف شده و ابزارهای عمومی در «اشیا» قرار می‌گیرند.
- «پوشاک» در فهرست اصلی ۱۶‌ستونی نیست.
