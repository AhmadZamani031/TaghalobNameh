# وضعیت پروژه
آخرین به‌روزرسانی: 2026-11-17

## وضعیت کلی
- حرف «ا» (شامل «آ») گردآوری و سطح‌بندی شده است.
- حرف «ب» با ۲۱۲ رکورد گردآوری شد؛ ۲۱۱ واژه انتخاب و ۱ واژه ذخیره شد. انتخاب سطح، کنترل تکرار و ثبت بانک مرکزی و Excel تکمیل شد؛ ۱۵ مدخل مرجع مستقیم دارند و ۱۹۷ مدخل نیازمند تکمیل منبع‌اند.
- حرف بعدی در صف و مرحله بعد: «پ».
- کنترل منبع و املا برای رکوردهای فاقد مرجع مستقیم کافی در T12 ادامه می‌یابد؛ بازبینی کاربر پیش‌شرط ادامه حروف نیست.

- [x] T02 — دسته‌بندی ۸/۱۲/۱۶
- [x] T03 — بانک داده و Excel مدیریتی
- [x] T04 — دستورالعمل پژوهش
- [x] T05 — نمونه‌سازی (طبق تصمیم مدیر پروژه، اجرا لازم تشخیص داده نشد)
- [x] T06 — ارزیابی نمونه (طبق تصمیم مدیر پروژه، اجرا لازم تشخیص داده نشد)
- [x] T07 — گردآوری اولیه حرف «ا»
- [x] T08 — انتخاب و تثبیت سطح حرف «ا»
- [x] T13 — گردآوری حرف «ب»
- [x] T14 — انتخاب و تثبیت سطح حرف «ب»
